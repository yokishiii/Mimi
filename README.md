# 🤖 MiMi – AI Chatbot

MiMi is a lightweight yet professional **AI Chatbot** built with **Python (Flask)** for the backend and **HTML/CSS/JS** for the frontend.  
Designed as a **college project**, MiMi demonstrates how to create an interactive conversational AI with a clean UI and scalable backend.

---

## 🚀 Features
- 🖥️ **Frontend (HTML + CSS + JS)** – Responsive and modern chat interface.  
- 🐍 **Backend (Python Flask)** – REST API for chatbot communication.  
- 🔄 **Asynchronous Communication** – AJAX-powered smooth chat without reloading.  
- 🎨 **User-Friendly Design** – Simple, minimal, and professional look.  
- 🧠 **Custom Chatbot Logic** – Rule-based replies (upgradeable with NLP/ML).  
- 🌍 **Cross-Origin Ready** – Integrated with `flask-cors` for frontend-backend connectivity.  

---

## 🛠️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/<your-username>/MiMi-Chatbot.git
cd MiMi-Chatbot
````

### 2️⃣ Install dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 3️⃣ Run the backend server

```bash
python app.py
```

Backend will start at: `http://127.0.0.1:5000`

### 4️⃣ Open the frontend

Open `frontend/index.html` in your browser and start chatting 🎉
